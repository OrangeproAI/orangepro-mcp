# 0.2.60: static-only runs and zero budgets

Fold into `0.2.60.md` at release.

## Static-only mode (new)
- `opro start --static-only`, or `ORANGEPRO_STATIC_ONLY=1`, reads a repository and drafts tests without running any of its code. Proof (both lanes), runtime coverage and the Go compile check are skipped. Go drafts are kept and marked "Not compile-checked".
- As a backstop, the proof runner, prove-loop setup commands, coverage runs and containers refuse to start in this mode.
- For runs on code you do not trust, such as a free report on a public repository.

## Fixes
- `--proof-limit 0` now means no proof attempt. Before, the CLI read 0 as "not given" and used the default budget (up to 5 attempts).
- `--generate-limit 0` now means no drafts. Before, it drafted the default 20.
- The Python draft check runs isolated (`python3 -I`, from the draft's temporary folder). Before, a repository file named `ast.py` or `py_compile.py` in the working directory could run during the check.

Nothing changes for a run without `--static-only`, the variable or a 0 budget: same graph, ranking, reports and reuse key.
