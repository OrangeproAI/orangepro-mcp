# 0.2.43


## Python and FastAPI structural analysis

- Python class methods now use owner-qualified identities such as `Class.method`, preventing collisions when multiple classes define the same method name.
- FastAPI decorator routes, `api_route(...)`, and static `add_api_route(...)` registrations produce collision-resistant endpoint contracts and handler links. Statically visible local router prefixes are composed; unresolved cross-file composition is labeled rather than guessed.
- Statically named `Depends(...)` and `Security(...)` dependencies add framework-derived graph links.
- Concrete Python functions and methods reached from a FastAPI handler through at most three exact static calls can enter the behavior denominator. The graph records the seed, edge kinds, and hop count; this is a Python-only structural recalibration.
- Python class containers remain graph and denominator nodes but no longer compete with their concrete methods in the primary priority worklist.
- Imported persistence-shaped destructive calls and receiver-field destructive calls can inform irreversible-sink scoring. Generic third-party delete methods, common local/list/filesystem calls, and `TYPE_CHECKING` imports remain excluded from this sink path.

## Release safety

- The graph schema is now `orangepro.local_graph.v3`; existing graphs rebuild because Python method identities changed.
- The analyzer identity is now `orangepro.analyzer.v2`.
- `prepublishOnly` now requires typecheck, build, and the full test suite.
- Package-surface tests accept the observed npm 10 array and npm 12 package-map dry-run JSON formats.
- The release helper aligns root, wrapper, registry, and lockfile versions without running a broad dependency update.

## Evidence semantics

All FastAPI, dependency, call, and test associations above are static graph facts. They may support **Associated** status. They do not create **Proven** status. Proven still requires execution plus a targeted killed mutation.
